# Health Records: Example Structure

*Illustrative structure only. Owned by Mira. Each person tracked gets three
files. No real health information appears in this repository.*

## `[Name]_Doctor_Visit_Guide.docx`: living, appointment-facing
Bring this one. Updated the same day new information arrives.

1. Header: prepared by, "LIVING DOCUMENT", Last updated date
2. How to use this document
3. Today's appointment: intake essentials (diagnoses, medications, allergies,
   surgeries, prior tests, family history), each gap marked `[NEEDED]` rather
   than guessed
4. Current concerns in priority order, each with a scripted line in italics to
   read aloud
5. Tests and referrals to ask for
6. Symptom timeline: facts as reported, no interpretation
7. Red flags: seek care without waiting
8. Still Needed / Bring to Appointment
9. Visit Record table: date, provider, discussed, ordered, outcome
10. Change Log table: one dated row per update, including corrections
11. Footer on every page: "Page X of Y" from live fields

## `[Name]_Health_Synopsis.docx`: full background and analysis
Symptom analyses in the standard format: symptoms, situational factors, leading
explanation, at least two alternatives with what would rule each in or out,
next steps by urgency, when to escalate.

## `[Name]_Health_Tracking.xlsx`: readings over time
Every sheet carries a "Page X of Y" print footer.

| Sheet | Columns |
|---|---|
| Orthostatic Vitals | Date, Time, Test Type, Timepoint, HR, HR change, BP systolic, BP diastolic, Symptoms, Notes |
| Daily Log | Date, Sleep hours, Sleep quality, Resting HR, HRV, Activity, Fluids, Salt, Symptoms, Severity, Heat exposure, Meds taken, Notes |
| Labs | Date, Test, Result, Units, Reference range (the lab's own), Flag, Ordering provider, Notes |
| Medications | Medication, Dose, Frequency, Start, End, Prescriber, Treating, Side effects (discontinued medications stay, with an end date) |
| Appointments | Date, Provider, Specialty, Reason, Questions to ask, Outcome, Follow-up due |
| Genetics | Date added, Source, Link, Gene, Variant, Genotype, Classification, Condition, Status, Notes |
| Reference | Published diagnostic criteria, with source |
