## Conventions shared by every file

- **Dated entries.** A confirmation, correction, or approval carries its date,
  so a later change is visible as a change.
- **Resolved questions stay listed, struck through, with the answer.** An
  unmarked resolved question gets asked again.
- **Confirmed absences are written as loudly as strengths**, with the adjacent
  truth that can be claimed instead.
- **Gaps are marked, not filled:** `[NEEDED]`, `[GAP: ...]`, `[INSERT: ...]`.
