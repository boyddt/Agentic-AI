# Words to Avoid: Example

*Illustrative content. Checked by Scout before any cover letter is finalized,
and by Remy for suggested interview answers.*

## Never Use
Absolute. No substitution; rewrite the sentence.

| Phrase |
|---|
| Move the needle |
| Paradigm shift |
| Synergy |
| Low-hanging fruit |
| Results-driven professional |
| Passionate about data |

## Avoid
Replace when a plainer word fits.

| Word | Prefer |
|---|---|
| Leverage | Use |
| Utilize | Use |
| Spearheaded | Led |
| Robust | (name the actual property) |

## Punctuation
- No em dashes. Use a comma, colon, semicolon, or parentheses. Em dashes are a
  strong AI-writing signal.

## Repetition
Any word used more than twice in one letter is flagged for review.
